# Cerca (nombre provisional) · versión de prueba

Versión pública de **prueba** de una plataforma para descubrir negocios locales en Roldanillo, Valle del Cauca (Colombia).

- **Todos los negocios y contactos que aparecen son ficticios** (datos de demostración).
- Mapa: [MapLibre GL JS](https://maplibre.org/) con teselas de [OpenFreeMap](https://openfreemap.org/), © [OpenStreetMap](https://www.openstreetmap.org/copyright).
- Este repositorio solo contiene los archivos estáticos publicados; el desarrollo se hace en otro lugar.
